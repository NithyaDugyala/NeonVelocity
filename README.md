# Neon Velocity

A 3D endless runner game built in Unity. Run down a neon-lit city track, dodge obstacles, collect coins and beat your high score.

## Gameplay
- Run forward automatically and switch lanes
- Jump over obstacles (pink X crates)
- Collect coins along the track
- Score and distance increase as you run
- The game ends when you hit an obstacle, then tap Play Again

## Controls
- Jump: JUMP button / [key, e.g. Space]
- Move: [e.g. Left/Right arrows or A/D]
- Pause and Restart: buttons at top left
